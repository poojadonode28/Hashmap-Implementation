# Custom HashMap Implementation in Java

A simple implementation of Java's `HashMap` using generics, buckets, and linked lists.

### Features
- `put(key, value)` – Insert or update entries.
- `get(key)` – Retrieve values by key.
- `remove(key)` – Remove entries.
- Collision handling using separate chaining.
- Dynamic resizing through rehashing when the load factor exceeds `0.7`.

### Concepts Learned
Java Generics, Hashing, Linked Lists, Load Factor, and Rehashing.
